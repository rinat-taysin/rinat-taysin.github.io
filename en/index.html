How I work

  • Routine first, model second

    I find where people actually lose hours and automate the most frequent work first. Anything that can be computed is computed in code.

  • Agents prepare, people decide

    Money, people, deadlines and anything irreversible go to a human as one question: options, a recommendation, and what happens by default.

  • Agent permissions live in code

    Action allow-lists, hooks, a merge guard, secrets the agent can use but never see. The prompt isn’t what keeps it in bounds.

  • Live data stays in the tracker

    Agents work where the team already works: Jira, Linear, messengers, the calendar. Nobody has to learn a new tool.
